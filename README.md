Password Checker

Descripción

Password Checker es un programa desarrollado en Python que permite evaluar de forma sencilla si una contraseña cumple 
con algunos requisitos básicos de seguridad.

El programa solicita una contraseña al usuario y verifica si cumple con las siguientes condiciones:

* Tener al menos 8 caracteres.
* Contener al menos un número.
* Contener al menos una letra mayúscula.

Si la contraseña cumple todos los requisitos, el programa indica que es válida. 
Si no los cumple, muestra específicamente qué requisito hace falta.

Problema que resuelve:

Crear una contraseña puede parecer sencillo, pero es importante verificar que tenga algunos elementos básicos que dificulten 
su uso como una contraseña débil.

Este proyecto automatiza una comprobación básica de una contraseña y permite al usuario identificar rápidamente qué requisitos
necesita mejorar.

Tecnologías utilizadas:

Python 3

Funcionamiento:

El programa sigue estos pasos:

1. Solicita al usuario que introduzca una contraseña.
2. Comprueba que tenga como mínimo 8 caracteres.
3. Recorre cada carácter de la contraseña.
4. Comprueba si existe al menos un número.
5. Comprueba si existe al menos una letra mayúscula.
6. Muestra si la contraseña cumple los requisitos.
7. Si no los cumple, indica exactamente qué requisito falta.
